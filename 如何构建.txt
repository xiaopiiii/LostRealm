Lost Realm —— 源码包说明
版本：1.0.0-beta28
================================================================

【这是什么】
Minecraft 1.20.1 Forge 模组的完整源码（Java + 资源 + 构建脚本 + 贴图生成工具）。
配好前置后可直接构建出 "Lost Realm-1.0.0-beta28.jar"。

【目录结构】
  src/main/java/com/lost_realm/   Java 源码（核心，241 个文件）
  src/main/resources/             资源：语言文件、贴图、模型、配方、数据包、音效
  tools/                          造型/贴图生成脚本（Python，非构建必需）
  libs/                           ★ 前置模组 jar 放置目录（默认为空，jar 需自行下载）
  build.gradle / gradle.properties / settings.gradle   构建脚本
  gradle/ + gradlew + gradlew.bat Gradle Wrapper（无需另装 Gradle）
  README.md                       完整开发文档（14 万字，含大量踩坑记录）
  .codebuddy/项目规则.md           必须长期遵守的项目约定（改代码前先读）

【构建前置】
1. JDK 17（必须是 17）
2. 以下 2 个 jar 必须自行下载后放进 libs/（源码包不含，避免二次分发）：
     goety-2.5.58.4.jar                诡厄巫法，法师勋章底座
                                       https://www.curseforge.com/minecraft/mc-mods/goety/files
     geckolib-forge-1.20.1-4.4.9.jar   实体骨骼动画（必须 4.4.x，4.7+ 是 NeoForge 线）
                                       https://www.curseforge.com/minecraft/mc-mods/geckolib/files
   文件名前缀匹配 goety-*.jar / geckolib-*.jar 即可，但不要同时放多个版本。

   缺失时 Gradle 会直接报错，并打印需要的版本与下载地址。

3. 以下依赖由 build.gradle 的 maven 坐标自动下载，不需要手动放：
     Curios 5.14.1+1.20.1
     Apothic Attributes 1.20.1-1.3.7
     Placebo 1.20.1-8.6.0

【构建命令】
  ./gradlew build

  产物：build/libs/Lost Realm-1.0.0-beta28.jar

  ⚠️ 首次构建需联网（下载 Forge / Minecraft 依赖，约 500MB）。
     之后依赖已进 ~/.gradle 缓存，可加 --offline 加速。

【版本号规则（重要）】
  改 gradle.properties 里的 mod_build（beta28 → beta29）一个值即可，
  它会同时决定：
     模组列表里显示的版本号  →  Lost Realm 1.0.0-beta29
     jar 文件名              →  Lost Realm-1.0.0-beta29.jar
  ⚠️ 拼出来的版本号必须以数字开头：Forge 的校验正则是 ^\d+.*，
     写成 "beta29" 会直接拒绝加载整个模组（dv1~dv4 就是这么崩的）。

【贴图/模型修改】
  tools/ 下的 gen_*.py 是各套贴图与模型的生成脚本（Python + Pillow + numpy），
  改完参数重跑即可重新生成对应 PNG / geo。
  注意：二阶段模型只走 tools/bbmodel_to_gecko.py，
       旧的 gen_geo.py / gen_anim.py 已废弃，不要再用。

【常见问题】
  症状 → 真因 → 修法，见 .codebuddy/项目规则.md 的「§4 静默失效速查」。
  排查顺序固定：剔除盒 → 渲染器是否被调用 → 坐标基准 → 同步数据。
